## Method

- **Tier 1 (automated)**: the plugin registers with the host, `start()` does not throw, and none of its source patches fail. Measured from the end-of-run snapshot, which subsumes load time: failed starts never retry and patch notices are cumulative, so a late patch failure is conservatively counted here.
- **Tier 2 (automated)**: with all acceptance plugins enabled, the session soaks for the window above in a read-only state; no uncaught error is attributable to the plugin and no patch of its fails. A pass is only claimed when the soak reached 120s; shorter runs report "not run".
- **Tier 3 (owner, pending)**: the last column is the checklist — run each line by hand on a logged-in session. Nothing in this document is Tier-3-verified.
- Environment: fresh isolated profile, no login (`--ion-profile`), hidden offscreen window, idle I/O priority. Read-only: no messages, joins, or account changes.
